# FSOC Datasets Directory

**Team PHARO — SIH26169**

This directory stores generated telemetry time-series, recorded synthetic camera frames, and scenario run logs.

- `scenarios/`: Saved JSON scenario configuration files.
- `telemetry/`: CSV / HDF5 / Parquet exported tracking telemetry runs.
- `frames/`: Synthetic focal plane imagery recordings for dataset generation and YOLO detector offline training.
