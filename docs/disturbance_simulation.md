## 1. Purpose & Overview
The **Disturbance & Noise Simulation Module** models realistic environmental, mechanical, and sensor imperfections that corrupt optical receiver observations in Free-Space Optical Communication (FSOC) coarse alignment systems.

It takes the clean synthetic camera frame generated by the Virtual Camera (Module 3) and applies a deterministic multi-stage disturbance pipeline:

```
CLEAN SYNTHETIC CAMERA IMAGE
             ↓
[1. Platform Vibration / Image Jitter]
             ↓
[2. Optical & Atmospheric Blur]
             ↓
[3. Sensor Electronic & Thermal Noise]
             ↓
[4. Scintillation Deep Fades & Dropouts]
             ↓
DISTURBED SENSOR OBSERVATION (For Future Detector)
```

> [!IMPORTANT]
> **Strict Architectural Boundary**: The disturbance module simulates camera and environmental imperfections. It **does NOT** perform beacon detection, blob extraction, OpenCV thresholding, YOLO inference, Kalman state estimation, or gimbal control. Its output is an unannotated degraded sensor image intended for downstream detection algorithms.

## 2. Input / Output Data Contract

### 2.1 Input Contract
- Clean synthetic 2D grayscale image array $I_{\text{clean}} \in \mathbb{R}^{H \times W}$ (`uint8`, $[0, 255]$).
- Camera frame metadata: timestamp $t$, frame index $k = \operatorname{round}(t \cdot \text{FPS})$, sensor dimensions ($W \times H$), ground-truth projected beacon coordinates $(u, v)$, spot radius, and visibility state.
- Disturbance configuration parameters (`DisturbanceConfig`).
- Master simulation random seed (`random_seed`).

### 2.2 Output Contract (`DisturbanceFrame`)
- Disturbed 2D grayscale image array $I_{\text{disturbed}} \in \mathbb{R}^{H \times W}$ (`uint8`, $[0, 255]$).
- Disturbance diagnostics metadata (`DisturbanceMetadata`): applied severity, individual effect parameters ($\sigma$, blur kernel, jitter offset $dx, dy$, dropout active state), and applied effect counts.

## 3. Mathematical Disturbance Models

### 3.1 Sensor Noise (Additive Gaussian Noise)
Models sensor electronic read noise, thermal dark current noise, and background optical shot noise:

$$I_{\text{noisy}}(x, y) = \operatorname{clip}\left( I(x, y) + \mathcal{N}(0, \sigma^2), \, 0, \, 255 \right)$$

where $\sigma$ is derived from `noise_magnitude`:
$$\sigma = \begin{cases} \text{magnitude} \cdot 255.0 & \text{if } \text{magnitude} \le 1.0 \\ \text{magnitude} & \text{if } \text{magnitude} > 1.0 \end{cases}$$

- **RNG Seed Derivation**:
  $$\text{seed}_{\text{frame}} = (\text{master\_seed} \cdot 1000003 + k \cdot 997 + 17) \pmod{2^{32}}$$
  Guarantees 100% bit-exact reproducibility for identical $(\text{seed}, k)$ pairs while producing independent random noise fields per frame.

---

### 3.2 Optical & Atmospheric Blur
Models atmospheric optical turbulence Point Spread Function (PSF) dispersion, receiver lens defocus, and dynamic motion blur:

$$I_{\text{blurred}} = I * G_{2D}(\sigma_{\text{blur}})$$

$$G_{2D}(x, y) = \frac{1}{2\pi \sigma_{\text{blur}}^2} \exp\left( -\frac{x^2 + y^2}{2 \sigma_{\text{blur}}^2} \right)$$

where $\sigma_{\text{blur}} = \text{blur\_strength}$.
- **Kernel Size**: $D_{\text{kernel}} = 2 \lceil 2 \sigma_{\text{blur}} \rceil + 1$ (strictly odd and positive).
- **Edge Safety**: Preserves image dimensions and uint8 format without numerical overflow.

---

### 3.3 Platform Vibration & Image-Plane Jitter
Simulates mechanical vibrations induced by UAV multi-rotor dynamics, aircraft engine acoustic excitation, and mast sway as harmonic 2D translational image jitter:

$$dx(t) = A_x \cdot \sin(2\pi f_x t + \phi_x)$$

$$dy(t) = A_y \cdot \sin(2\pi f_y t + \phi_y)$$

where:
- $A_x = \text{vibration\_magnitude}$ (pixels)
- $A_y = \text{vibration\_magnitude} \times 0.8$ (pixels)
- $f_x = 5.0\text{ Hz}, \quad f_y = 7.0\text{ Hz}$
- $\phi_x = 0.0, \quad \phi_y = \frac{\pi}{4}$

**Border & Image Shift Policy**:
- Image is shifted by $(dx, dy)$ using continuous sub-pixel affine translation.
- Border pixels exposed by the translation are filled with black ($0$).
- **Strictly NO wrapping** around opposing image boundaries.

---

### 3.4 Scintillation Deep Fades & Beacon Dropout
Simulates catastrophic atmospheric deep fades, cloud blockages, and transient line-of-sight dropouts without running any computer vision detector.

- **Triggering Model**:
  For each distinct simulation frame index $k$, if no dropout is currently active and beacon is visible:
  $$\text{roll} \sim \mathcal{U}(0, 1)$$
  $$\text{Trigger Dropout if } \text{roll} < \text{dropout\_probability}$$
- **Duration Persistence**:
  When triggered at timestamp $t_{\text{trig}}$, dropout state remains active for the full configured `dropout_duration`:
  $$\text{Active until } t \ge t_{\text{trig}} + \text{dropout\_duration}$$
- **Occlusion Mechanism**:
  When active and beacon is visible, the spot region at ground-truth focal plane coordinates $(u, v)$ is occluded/zeroed out over a radius $r_{\text{occlude}} = \max(6.0, r_{\text{spot}} \times 2.5)$.

## 4. Severity Presets

| Severity | Vibration Magnitude | Noise $\sigma$ (8-bit) | Blur Strength | Dropout Probability | Dropout Duration |
|---|---|---|---|---|---|
| **`OFF`** | $0.0\text{ px}$ | $0.0$ | $0.0$ | $0.0$ | $0.0\text{ s}$ |
| **`LOW`** | $1.0\text{ px}$ | $12.8$ ($0.05$) | $1.0$ | $0.05$ ($5\%$) | $0.2\text{ s}$ |
| **`MEDIUM`** | $3.0\text{ px}$ | $30.6$ ($0.12$) | $2.0$ | $0.15$ ($15\%$) | $0.4\text{ s}$ |
| **`HIGH`** | $6.0\text{ px}$ | $63.8$ ($0.25$) | $3.5$ | $0.30$ ($30\%$) | $0.6\text{ s}$ |

## 5. REST API Reference

| Method | Endpoint | Description | Status Codes |
|---|---|---|---|
| `POST` | `/disturbance/initialize` | Initialize disturbance engine from `ScenarioConfig` | `200`, `400` |
| `POST` | `/disturbance/reset` | Reset temporal tracker and stochastic sequence to $t=0$ | `200`, `409` |
| `POST` | `/disturbance/config` | Update active disturbance parameters in real time | `200`, `400` |
| `POST` | `/disturbance/process` | Step/process clean frame through disturbance pipeline | `200`, `409` |
| `GET` | `/disturbance/frame` | Retrieve latest disturbed frame metadata | `200`, `409` |
| `GET` | `/disturbance/image` | Retrieve disturbed synthetic sensor image as PNG | `200`, `409` |
| `GET` | `/disturbance/status` | Retrieve module lifecycle status and active severity | `200` |
| `GET` | `/disturbance/telemetry` | Retrieve real-time disturbance diagnostics | `200`, `409` |
